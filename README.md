## Описание проектика

Программа на JavaScript проверяет, является ли массив чисел симметричным. Массив симметричен, если его элементы одинаково расположены относительно центра: он читается одинаково слева направо и справа налево.

## Функция `isSymmetric()`

Функция принимает массив чисел `symbols` и возвращает:

- `true` — если массив симметричный;
- `false` — если массив несимметричный.

## Принцип работы

1. Определяется индекс последнего элемента массива.
2. Цикл `for` проходит по первой половине массива.
3. Каждый элемент сравнивается с элементом на противоположной стороне.
4. Если элементы не совпадают, функция возвращает `false`.
5. Если все пары совпадают, функция возвращает `true`.

## Примеры работы

| Массив | Результат |
|---|---|
| `[2, 5, 7, 5, 2]` | `true` |
| `[4, 1, 3, 1, 4]` | `true` |
| `[2, 5, 7, 4, 2]` | `false` |
| `[9, 9, 9, 9]` | `true` |
| `[1, 2]` | `false` |
| `[6]` | `true` |

## Запуск программы

1. Установить Node.js.
2. Сохранить код программы в файл `script.js`.
3. Открыть терминал в папке проекта.
4. Выполнить команду:

```bash
node script.js
```

## Результат

Программа выводит в консоль результаты проверки каждого массива:

```text
true
true
false
true
false
true
```

## Вывод

Создана функция `isSymmetric()`, которая проверяет симметричность массива с помощью цикла `for` и сравнения элементов с противоположных концов массива.
